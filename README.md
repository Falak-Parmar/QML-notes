# Quantum Machine Learning (IT401)

This repository contains structured notes for the **IT401 – Quantum Machine Learning** course.

The notes are written in Markdown and published as a website using **MkDocs Material**.

## 📚 Contents
- Course overview and quantum algorithms
- Mathematical prerequisites (Probability & Linear Algebra)
- Quantum machine learning models and hybrid approaches

## 🌐 Live Website
👉 https://falak-parmar.github.io/QML-notes/

## 🛠 Built With
- MkDocs
- MkDocs Material
- MathJax (for equations)

## 🚀 Local Development
```bash
python -m venv .venv
source .venv/bin/activate
pip install mkdocs-material
mkdocs serve
```
